NEXT STEPS:
-----------
1. Build the package (EASY WAY):
   cd analytics-next/packages/node
   .\build-standalone.bat        (Windows)
   ./build-standalone.sh         (Linux/Mac)

   OR (MANUAL WAY):
   cd analytics-next/packages/node
   cd ../generic-utils && npm install && npm run build
   cd ../core && npm install && npm run build
   cd ../node && npm install && npm run build

2. Test locally (optional):
   npm install /path/to/analytics-next/packages/node
   
3. Publish to npm:
   npm login
   npm publish --access public

4. Install in your backend apps:
   npm install @bratrax/analytics-node

5. Use it:
   import { Analytics } from '@bratrax/analytics-node'
   const analytics = new Analytics({ writeKey: 'vidtao-test-write-key' })
   analytics.track({ userId: '123', event: 'Payment Processed' })

BACKEND API ENDPOINT REQUIRED:
------------------------------
POST https://api.bratrax.com/vidtao/batch

Request Body:
{
  "batch": [ array of events ],
  "writeKey": "vidtao-test-write-key",
  "sentAt": "2024-01-19T10:00:00.000Z"
}

Response:
- 200-299: Success
- 400: Bad request (won't retry)
- 429: Rate limited (will retry)
- 500+: Server error (will retry)

FEATURES:
---------
✅ Track events (track, identify, page, group, alias, screen)
✅ Automatic batching (configurable)
✅ Automatic retries with backoff
✅ Error handling
✅ Graceful shutdown with closeAndFlush()
✅ Works in Node.js, AWS Lambda, Cloudflare Workers, etc.
✅ Same API as Segment's analytics-node

CONSISTENCY WITH BROWSER VERSION:
----------------------------------
✅ Same API endpoint (api.bratrax.com)
✅ Same write key (vidtao-test-write-key)
✅ Similar plugin architecture
✅ Batched requests
✅ Custom plugin approach

USAGE EXAMPLE:
--------------
// Initialize
const analytics = new Analytics({ writeKey: 'vidtao-test-write-key' })

// Track backend events
analytics.track({
  userId: 'user123',
  event: 'Payment Processed',
  properties: { amount: 99.99, currency: 'USD' }
})

// Identify users
analytics.identify({
  userId: 'user123',
  traits: { email: 'user@example.com', plan: 'premium' }
})

// Graceful shutdown
await analytics.closeAndFlush()
